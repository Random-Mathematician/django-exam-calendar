# Exam Calendar
A personal Django WSGI webapp server for helping with exam date management.

This repo constitutes the required files needed for Vercel to host the server. It is intended to be a semiprivate website to help professors and students alike set exam dates without collisions with other tests.

## Version history
- v0.0, the repo is created.
- v0.1, waiting on user auth, made the actual calendar display mostly functional (w/o the exams).
- v0.2, added views for creating exams and special dates.
- v1.0, added user auth, managing & deleting exams, Vercel-needed files and lots more. Ready for the first real deployment.
